Tabular DataStructured rows and columns, like spreadsheets and databases
Linear RegressionSupervised

How it works: Fits a straight line through labeled data points and uses it to predict a number.

Use case: Forecasting house prices from size and location, or predicting monthly sales.

Key strength: Simple, fast, and easy to explain to non-technical teams.

Decision TreeSupervised

How it works: Splits data with a chain of yes/no questions until it reaches a prediction.

Use case: Approving or declining loan applications based on income and credit history.

Key strength: Reads like a flowchart, so every decision can be explained.

Random ForestSupervised

How it works: Trains many decision trees on random samples of the data and lets them vote.

Use case: Detecting fraudulent card transactions and predicting customer behavior.

Key strength: More accurate and stable than a single tree, and resists overfitting.

Gradient BoostingSupervised

How it works: Builds trees one after another, with each new tree fixing the previous tree's mistakes.

Use case: Credit risk scoring, customer churn prediction, and ranking search results.

Key strength: Often the top performer on structured business data.

K-Means ClusteringUnsupervised

How it works: Groups unlabeled points around a chosen number of center points, adjusting until stable.

Use case: Segmenting customers by buying behavior for targeted marketing.

Key strength: Finds hidden groups without needing any labels.

PCAUnsupervised
TabularVision

How it works: Compresses many features into a few new ones that keep most of the variation.

Use case: Reducing noise, speeding up models, and visualizing complex data in 2D.

Key strength: Simplifies large datasets while keeping the important patterns.

Computer Vision and NLPDeep learning for images and for language
Convolutional Neural NetworkSupervised
Computer Vision

How it works: Slides small filters over an image to detect edges, then shapes, then whole objects.

Use case: Spotting tumors in X-rays, reading license plates, and detecting objects in photos.

Key strength: Learns visual features on its own, with no hand-built rules.

Transformer (BERT, GPT)Supervised
NLPGenerative AI

How it works: Uses attention to weigh how every word relates to every other word, learning from the text itself.

Use case: Sentiment analysis, chatbots, translation, and text generation.

Key strength: Understands context across long passages and powers modern GPT models.

Generative AIModels that create new images, text, and more
Generative Adversarial NetworkUnsupervised
Generative AIComputer Vision

How it works: A generator creates fakes while a discriminator tries to spot them, until the fakes look real.

Use case: Creating realistic faces, enhancing photos, and making synthetic training images.

Key strength: Produces sharp, realistic images without needing labeled data.

Diffusion ModelUnsupervised
Generative AIComputer Vision

How it works: Learns to remove noise step by step, then builds a brand-new image starting from pure noise.

Use case: Text-to-image tools such as Stable Diffusion for art, design, and marketing.

Key strength: Creates detailed, high-quality images that follow a text prompt closely.

How to choose

Spreadsheet-style dataStart with Random Forest or Gradient Boosting, which handle mixed columns well. Use Linear Regression or a Decision Tree as a simple, explainable baseline.
ImagesUse a CNN to classify pictures or detect objects, since it learns visual patterns on its own. Apply PCA first if the image data is very large.
TextUse a Transformer to capture meaning and context in language. It suits sentiment analysis, search, and chatbots, and pretrained models save time and data.
New contentUse a GAN or Diffusion model to generate images, and a Transformer like GPT to generate text. Check outputs carefully for quality and bias.
